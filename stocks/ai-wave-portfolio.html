The whole strategy in five lines

  1. Always own the platforms that convert AI into cash (cloud + distribution) — never fully exit.
  2. Overweight picks & shovels while scarce (chips, memory, networking, power gear) — trim hard when growth decelerates.
  3. Build power + cloud utilisation as the multi-year backlog (Phase 2).
  4. Add workflow software only after paid AI attach is proven (Phase 3) — do not overpay early.
  5. Rebalance twice a year on rules below; ignore weekly narrative.

3 · 10-year rotation calendar

You do not need monthly trading. You need two reviews per year and pre-committed moves.

Now → 2027 · Phase 1 residual
Run Wave A hot; Core permanent; Wave B building; Wave C small
Target: Core 40% · A 25% · B 20% · C 15%. Harvest NVDA/MU strength into CEG/VRT/GEV if tools run ahead of fundamentals.
2027 → 2029 · Phase 2 dominance
Sell most of Wave A; Wave B becomes the growth engine; Core still largest
Target shift: Core 45% · A 8–12% · B 28–32% · C 15–18%. Keep a token NVDA/TSM stub only if still scarce. Cloud FCF recovery is the Core thesis test.
2029 → 2032 · Phase 3 scale-in
Grow Wave C with proof; hold Core; Wave B matures
Target shift: Core 45% · A 0–5% · B 20% · C 30%. Add CRM/vertical only if NRR + paid AI SKUs clear. Cut Wave B names that have re-rated to terminal growth.
2032 → 2035 · Phase 4 posture
Almost all capital in Core + proven apps; tools only if structural oligopoly remains
Target: Core 55%+ · C 30% · B 10% · A 0–5%. Book should look like a quality compounder portfolio that uses AI, not an “AI theme” basket.

4 · Simple operating rules (print this)

1 · Review twice a year

After hyperscaler capex season and after semi results cluster. No more than two discretionary trades outside reviews unless a kill rule fires.

2 · Second derivative rule (Wave A)

If NVDA or hyperscaler AI capex growth decelerates YoY, trim Wave A the same quarter — don’t wait for the narrative to die.

3 · Proceeds waterfall

Wave A sales → first into Wave B (power) underweight, then Core dips, then Wave C. Never recycle tool profits into more speculative AI apps.

4 · Wave C proof gate

Do not raise C above 20% until at least one of NOW/CRWD (or adds) shows disclosed AI attach + stable/rising NRR for two consecutive reports.

5 · Position caps

No single name > 20% (MSFT exception to 22% after run-up). Wave A total never > 30% after 2027.

6 · Kill switches (exit line)

Hyperscaler capex −15%+ YoY two seasons → cut Wave A to ≤10%. Tool GMs collapse structurally → exit NVDA/MU stubs. Core cloud growth < mid-single digits for a year → reassess entire thesis weight in equities.

Maximum profit ≠ maximum concentration in the hottest name. The path that historically fails is riding Phase 1 winners into Phase 2 with full size. This book forces rotation: tools pay for power; power and platforms fund applications; applications and platforms own the end-state surplus.

5 · What we deliberately left out (and why)

Simplicity is the point. Omitted on purpose:

  • Pure model labs / AI IPO wrappers — binary, no hold rule you can execute calmly.
  • SMCI-type ODMs — inventory and margin traps; exposure via NVDA/TSM is enough.
  • Every utility / every semi — CEG + GEV + VRT covers power stack; NVDA/TSM/MU/ANET covers silicon stack.
  • Meta as core — optional satellite later; ads thesis already partly in GOOGL; reduces overlap.
  • Leverage / options overlays — destroy the “simple 10-year” mandate.
