Both scores are 0–100. Fundamentals is a percentile composite (quality, growth, balance sheet, valuation) against the current filtered set. AI-leverage is a structural heuristic — industry fit + labor intensity + margin leverage — not fetched data; see the row detail (▸) for the exact rationale per name. Top-right = strong fundamentals with high structural AI leverage; use this as a starting shortlist, then read the row detail and the linked Yahoo Finance page before doing further work.
Methodology. Universe = every symbol Yahoo Finance lists with exchange code HEL (Nasdaq Helsinki) or STO (Nasdaq Stockholm), including First North growth-market names, plus the current S&P 500 constituent list (sourced from Wikipedia's maintained constituents table, since Yahoo's screener has no index-membership filter — fundamentals for every US name still come from the same Yahoo quoteSummary API as everything else, so the sector/industry taxonomy is consistent across the whole universe). Fundamentals fetched via Yahoo's quoteSummary API (price, assetProfile, summaryDetail, defaultKeyStatistics, financialData); all monetary figures converted to EUR at the latest spot FX. Cache: 24h per symbol (cache/screener/), stale-on-failure fallback; the S&P 500 constituent list itself is cached a week, since index membership rarely changes. Fundamentals score weights: Quality 35% (ROE, op/gross margin, ROA) · Growth 20% (revenue, EPS growth) · Balance sheet 15% (net debt/EBITDA, debt/equity, current ratio) · Valuation 30% (earnings yield, FCF yield, EV/EBITDA) — each a percentile rank within the full fetched universe (Nordics + S&P 500 together, computed once at fetch time — a Nordic name's score reflects its rank against the combined pool, not Nordic peers only). AI-leverage score = 0.75 × industry base-rate + 0.15 × labor-intensity percentile (lower revenue/employee → more automation upside) + 0.10 × gross-margin percentile (higher margin → efficiency gains drop straight to profit) — an explicit, inspectable heuristic, not a model prediction. Overall = 0.65 × Fundamentals + 0.35 × AI-leverage. Share classes / dual listings of the same company (e.g. GOOGL/GOOG) are flagged as duplicates (most-traded line kept primary) and hidden by default.

Refresh from a terminal: python utils/universe_screener.py (add --clear-cache to force a full refetch, --skip-sp500 for Nordics only) · serve with live refresh: python utils/screener_server.py · flat CSV twin: data/screener_latest.csv.

For analysis and education only — not investment advice, not a recommendation, not a price target. Scores quantify a set of explicit assumptions; they do not make those assumptions correct. Verify primary-source figures before acting.
